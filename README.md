# LEXICON — A World of Words

LEXICON is a multilingual dictionary project. The first milestone is a responsive, mobile-first English dictionary prototype that can be developed from an Android phone and later expanded into a native Android application.

## Current prototype

- Search English words using the Free Dictionary API.
- Display definitions, parts of speech, phonetic spelling, available audio, synonyms, antonyms and available word origins.
- Save words and retain recent searches in the browser on the device.
- Responsive dark interface designed for mobile screens.

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Project files

- `index.html` — application structure
- `style.css` — responsive visual design
- `script.js` — dictionary lookup, saved words and search history

## Roadmap

The long-term goal is a multilingual dictionary platform. English lookup is the first working data integration, not the limit of the product. Additional language datasets and APIs must be evaluated for accuracy, coverage, licensing, offline use and attribution before integration.

The current browser prototype is not yet a native Android APK. It can later be rebuilt with Kotlin and Jetpack Compose or packaged for Android after the core experience is validated.
